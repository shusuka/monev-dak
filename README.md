# MonevDAK

Aplikasi monitoring & evaluasi DAK Fisik Bidang Jalan: pre/post test, konfirmasi data ruas, dan berita acara eMonitoring.

Situs statis (HTML + Tailwind CDN + JS) dengan Firebase Firestore. Setelah mengubah `firestore.rules`, tempel isinya di Firebase Console → Firestore → Rules → **Publish**.
